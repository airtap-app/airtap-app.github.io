# AirTap listener

Live at https://airtap-app.github.io/ — AirTap builds the links (`https://airtap-app.github.io/#<stream code>`).

The page people open to listen to a live AirTap stream: lossless audio straight from the sender's Mac to the
browser over an encrypted WebRTC data channel. The public PeerJS server only introduces the two sides; it never
carries audio. The password never leaves the page.

Open it with the link AirTap gives you (it ends in `#` and a stream code).
